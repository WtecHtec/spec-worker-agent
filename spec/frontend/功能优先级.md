# 前端功能优先级排序

> **设计原则**：对齐服务端架构，优先打通「发消息 → SSE 实时步骤流渲染」核心路径，再逐步完善 HITL 交互、断点重连与异常鲁棒性。

---

## 阶段总览

| 阶段 | 核心目标 | 核心产出 | 依赖后端阶段 |
|---|---|---|---|
| **P0 核心链路** | 跑通登录、会话与任务步骤实时流渲染 | 基础布局、Chat 界面、`useTaskStream` Hook、步骤卡片 | P0 |
| **P1 功能闭环** | 断点续传、HITL 交互卡片与任务取消 | 自动重连补齐、HITL 交互组件、终止任务按钮、多轮对话 | P1 |
| **P2 异常与韧性** | 网络断线自动重试、限流与错误友好提示 | 指数退避重连、统一 Toast/Banner、配额拦截提示 | P2 + P3 |
| **P3 体验与质感** | 动效打磨、代码高亮、暗黑模式与移动端适配 | Framer Motion 平滑动画、Markdown 代码高亮、响应式侧边栏 | - |

## P0｜核心链路跑通（第一阶段）

> **目标**：用户能够登录、创建会话、发送消息，并能在界面上**实时看到 Worker 推送的每一步（思考、工具调用、最终结果）**。

### 1. 项目初始化与全局状态
```
- Next.js 14 (App Router) + Tailwind CSS + shadcn/ui 初始化
- Zustand Store 设计：
    ├── authStore: 保存 Token、用户信息、登录态
    ├── sessionStore: 当前会话 ID、会话列表
    └── taskStore: 活跃任务 ID、当前任务 steps Map（按 step_index 排序）
- Axios / Fetch API 客户端封装（自动带 Authorization: Bearer Token）
```

### 2. 鉴权与会话管理
```
- /login 与 /register 页面（表单校验、Token 写入 LocalStorage / Cookie）
- 路由守卫（未登录自动重定向至登录页）
- 侧边栏 SessionList 组件：
    ├── 历史会话列表（按 last_message_at 倒序）
    ├── 「新建会话」按钮（POST /sessions）
    └── 点击切换当前会话
```

### 3. 对话主界面与输入框
```
- ChatWindow 容器组件：
    ├── 消息列表渲染（USER 消息气泡 + AGENT 回复卡片）
    └── 底部 ChatInput（支持回车发送、Shift+Enter 换行）
- 发送消息逻辑（POST /sessions/{id}/messages）：
    ├── 立即在 UI 插入 USER 消息与 AGENT 占位气泡
    └── 获取 task_id 并自动启动 SSE 监听
```

### 4. 核心 Hook：`useTaskStream`
```ts
// 前端实时能力的心脏
useTaskStream(taskId, {
  fromStep: 0,
  onStep: (step) => updateTaskSteps(taskId, step),
  onComplete: (result) => markTaskDone(taskId, result),
  onError: (err) => markTaskFailed(taskId, err),
});
```

### 5. 核心打字机效果（Typewriter Effect）与高性能流式渲染优化
```
- useTypewriter Hook（高性能 rAF 逐帧驱动）：
    ├── 基于 requestAnimationFrame (rAF) 逐帧批量吐字，拒绝高频 setInterval/setState 引起的掉帧
    ├── 动态缓冲池（Buffer Queue）：根据 SSE 推送速率动态调整单帧字符量，无延迟积压
    ├── 闪烁光标（Blinking Cursor: ▌）纯 CSS GPU 硬件加速动画
    └── 历史/重连数据识别（仅对当前流式步骤执行 rAF 动画，历史消息瞬时直出）
- 渲染性能与按需加载（On-Demand Rendering）：
    ├── 细粒度组件隔离（React.memo）：仅当前活跃 Step 触发重绘，历史已完成 Step 零重绘
    ├── 动态按需加载（next/dynamic）：代码高亮器 (Prism/Shiki)、图表组件 (Chart.js) 异步按需加载
    └── rAF 智能节流滚动（Auto-Scroll）：仅在用户处于底部时随打字平滑吸底，用户上滑查看历史时自动暂停吸底
- 步骤组件体系：
    ├── ThinkingStepComponent：灰色微光渐变折叠卡片，思考内容打字流式呈现
    ├── ToolCallStepComponent：展示工具名、调用参数（JSON 高亮）与执行状态
    ├── ToolResultStepComponent：展示工具执行耗时 Badge 与返回结构化数据
    └── FinalStepComponent：Markdown 打字机流式渲染（边打字边解析，不碎裂语法）
```

**P0 验收标准**：
```
✅ 登录成功进入控制台
✅ 创建会话并发送“帮我分析销售数据”
✅ 界面基于 rAF 丝滑展开 Step 1 思考（60FPS 打字动画） → Step 2 查库 → Step 3 结果 → Step 7 报告（Markdown 流式输出）
✅ 快速大量输出时 CPU 占用低，无卡顿与重绘闪烁
```

## P1｜功能闭环与断点续传（第二阶段）

> **目标**：用户刷新页面或重新进入会话时**自动恢复未完结任务**；支持 **HITL 人工交互卡片**与**主动终止任务**。

### 6. 进入页面自动检测与断点重连
```
- 进入 /sessions/[id] 时：
    1. 调用 GET /sessions/{id}/messages 拉取全量历史消息
    2. 检查最后一条消息：若 status === 'streaming'，提取 task_id
    3. 获取当前已渲染的最大 step_index (设为 N)
    4. 自动调用 useTaskStream(task_id, { fromStep: N })
    5. 服务端先补齐历史步骤，再无缝切换实时推送
```

### 7. HITL 人工介入交互卡片
```
- 当收到 step_type === 'HITL_REQUEST' 或 event: 'hitl_created' 时：
    ├── 渲染专属 HitlCard 组件
    ├── 单选/多选按钮组（Choice）、文本输入框（Text Input）
    └── 「确认提交」按钮（POST /tasks/{id}/hitl/{hitl_id}/respond）
- 提交成功后：
    ├── 卡片状态变为「已确认」，锁定选项
    └── 任务继续向下执行后续步骤
```

### 8. 任务取消与状态互斥
```
- 任务执行中时：
    ├── 输入框变为「终止执行」红色按钮（或输入框置灰）
    └── 点击调用 DELETE /tasks/{id}
- 取消后：
    ├── 步骤流停止，当前消息显示「任务已取消」
    └── 输入框重新激活，允许开启下一轮任务
```

### 9. 多轮任务会话流转
```
- 第一轮任务完成后，输入框恢复可用
- 用户发送第二轮消息：
    ├── 生成新的 task_id，开启全新步骤流
    └── 历史轮次的步骤折叠为摘要，保持页面整洁
```

**P1 验收标准**：
```
✅ 任务执行中途按 F5 刷新网页，步骤无缝补齐并继续实时推送
✅ 遇到文件异常时，页面弹出选项卡片，用户点击“跳过”后任务继续完成
✅ 点击“终止执行”，任务立即中断且可以立刻开始下一轮发问
```

## P2｜异常恢复与连接鲁棒性（第三阶段）

> **目标**：保障在弱网、服务端短暂重启或触发限流时，前端具有极高的韧性和友好提示。

### 10. SSE 连接弹性与指数退避重连
```
- SSE 连接异常断开时：
    ├── 触发自动重连机制（初始 1s，最大 15s，指数退避）
    ├── 携带当前已收到的最新 step_index 重连，防止数据重复
    └── 重连成功后自动恢复
```

### 11. 网络状态感知指示条
```
- 顶部/连接状态小组件：
    ├── 🟢 已连接（实时同步中）
    ├── 🟡 正在重新连接（第 N 次尝试...）
    └── 🔴 网络失联 / 请检查网络
```

### 12. 统一错误提示与配额拦截
```
- 全局 Axios / Fetch 拦截器：
    ├── 401 Unauthorized → 清除 Token 并跳转登录页
    ├── 409 Conflict（会话已有任务运行）→ 弹出警告 Toast
    ├── 429 Quota Exceeded（并发任务数超限）→ 提示“已有 3 个任务正在运行，请等待完成后再试”
    └── 429 Rate Limit → 显示“请求过于频繁，请在 N 秒后重试”
```

## P3｜视觉动效与生产级体验（第四阶段）

> **目标**：打造媲美主流 AI 产品的高端交互与视觉质感。

### 13. Framer Motion 平滑动画
```
- 步骤卡片流式出现时的渐入与高度展开过渡动画
- Thinking 思考过程中的波纹脉冲（Pulse）效果
- 工具调用成功时的绿色勾选动画与耗时 Badge
```

### 14. 专业的 Markdown 与代码渲染
```
- react-markdown + remark-gfm 支持表格、任务列表
- 代码块高亮（Prism / Shiki）+ 一键复制按钮
- 图表组件渲染（支持 ECharts / Chart.js 展示报告中的数据图）
```

### 15. 响应式布局与暗黑模式
```
- 适配移动端（支持折叠式抽屉侧边栏）
- 基于 next-themes 的 Dark / Light 模式切换
- 会话重命名与删除确认弹窗
```
