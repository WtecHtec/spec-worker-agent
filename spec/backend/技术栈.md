# 最终技术栈

---

## 服务端（Python）

### 核心框架

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **语言** | Python 3.11+ | AI/LLM 生态最完整，团队熟悉 |
| **Web 框架** | FastAPI | 原生 async、内置 Pydantic 校验、SSE 友好、自动生成 API 文档 |
| **ASGI 服务器** | uvicorn | FastAPI 官配，高性能 |

### 数据层

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **ORM** | SQLAlchemy 2.0 async | Python 最成熟 ORM，支持乐观锁、FOR UPDATE SKIP LOCKED 等复杂查询 |
| **PG 驱动** | asyncpg | 比 psycopg2 快 3-5 倍，纯异步 |
| **数据库迁移** | Alembic | SQLAlchemy 官方配套，支持版本回滚 |
| **数据库** | PostgreSQL 15+ | 持久化存储，JSONB、LISTEN/NOTIFY 原生支持 |
| **缓存/队列/锁** | Redis 7+ | Stream 任务队列 + Pub/Sub 实时通知 + 分布式锁 |
| **Redis 客户端** | redis-py（async） | 官方维护，完整支持 Stream、Pub/Sub、Lua 脚本 |

### 工具层

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **数据校验** | Pydantic v2 | FastAPI 内置，v2 用 Rust 核心提速 5-50 倍 |
| **日志** | structlog | 结构化 JSON 日志，支持上下文绑定（task_id 自动带入），方便问题追踪 |
| **定时任务** | APScheduler | 轻量 async 定时器，用于心跳扫描和 HITL 超时检测 |
| **环境变量** | Pydantic BaseSettings | 启动时自动校验所有必需配置，缺少即报错 |
| **包管理** | uv | 比 pip 快 10-100 倍，支持虚拟环境和依赖锁定 |
| **测试** | pytest + pytest-asyncio | Python 主流测试框架，支持 async 测试 |

### 生产部署

| 类别 | 选型 |
|---|---|
| **多进程管理** | Gunicorn + UvicornWorker |
| **容器化** | Docker + Docker Compose |

## 前端（React）

### 核心框架

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **语言** | TypeScript | 类型安全，减少运行时错误 |
| **框架** | Next.js 14（App Router） | React 官方推荐，Server Components 支持首屏数据预取，内置路由 |
| **样式** | Tailwind CSS | shadcn/ui 依赖，原子化 CSS，定制灵活 |

### UI 组件

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **组件库** | shadcn/ui | 组件代码直接复制到项目，完全可控，AI 产品首选风格 |
| **图标** | Lucide React | shadcn/ui 官配图标库，风格统一 |
| **动画** | Framer Motion | 步骤逐条出现动画、HITL 卡片展开动画 |

### 状态管理

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **服务端状态** | TanStack Query | 会话列表、消息列表、任务状态的请求缓存和自动刷新 |
| **客户端状态** | Zustand | SSE 推送的实时步骤、连接状态、本地 UI 状态，轻量无样板代码 |

### 功能库

| 类别 | 选型 | 选型理由 |
|---|---|---|
| **SSE 管理** | 自封装 `useTaskStream` Hook | 需要携带 `from_step` 重连、step_index 去重，定制逻辑用原生 EventSource 封装 |
| **表单** | React Hook Form + Zod | HITL 表单交互，Zod 同时做运行时校验和 TS 类型推断 |
| **Markdown 渲染** | react-markdown + shiki | Agent 步骤内容的富文本渲染和代码高亮 |
| **HTTP 请求** | TanStack Query 内置 / fetch | 不引入 axios，减少依赖 |

## 环境变量完整配置

> 使用 Pydantic BaseSettings 管理，启动时自动校验，缺少必填项直接报错退出

### 服务端 `backend/.env`

```bash
# ─────────────────────────────────────────
# PostgreSQL 数据库
# ─────────────────────────────────────────
PG_HOST=localhost
PG_PORT=5432
PG_USER=agent_user
PG_PASSWORD=your_pg_password
PG_DB=agent_db
PG_POOL_SIZE=10                    # 连接池大小（生产建议 10-20）
PG_MAX_OVERFLOW=20                 # 连接池溢出上限
PG_POOL_TIMEOUT=30                 # 获取连接超时秒数
# 由以上字段自动拼接，也可直接设置覆盖：
# DATABASE_URL=postgresql+asyncpg://agent_user:your_pg_password@localhost:5432/agent_db

# ─────────────────────────────────────────
# Redis
# ─────────────────────────────────────────
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=                    # 无密码留空
REDIS_DB=0                         # 默认 DB
REDIS_MAX_CONNECTIONS=20           # 连接池大小
# 由以上字段自动拼接，也可直接设置覆盖：
# REDIS_URL=redis://:password@localhost:6379/0

# ─────────────────────────────────────────
# 鉴权
# ─────────────────────────────────────────
JWT_SECRET=your-jwt-secret-key-min-32-chars   # 必填，建议 openssl rand -hex 32 生成
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=10080           # Token 有效期（分钟），默认 7 天

# ─────────────────────────────────────────
# Agent 执行器
# ─────────────────────────────────────────
AGENT_MODE=mock                    # mock | llm
MOCK_FILES_DIR=./infrastructure/executor/mock  # mock JSON 文件目录

# 接入真实 LLM 时填写（AGENT_MODE=llm 时生效）
LLM_PROVIDER=openai                # openai | anthropic
LLM_API_KEY=                       # 必填（llm 模式）
LLM_MODEL=gpt-4o                   # 默认使用的模型
LLM_TIMEOUT=120                    # LLM 调用超时（秒）
LLM_MAX_RETRIES=3                  # 失败重试次数

# ─────────────────────────────────────────
# Worker 配置
# ─────────────────────────────────────────
WORKER_CONCURRENCY=4               # 单个 Worker 进程同时处理的任务数
WORKER_HEARTBEAT_INTERVAL=10       # 心跳更新间隔（秒）
WORKER_HEARTBEAT_TIMEOUT=60        # 超过此时间无心跳视为僵尸任务（秒）
WORKER_GRACEFUL_SHUTDOWN_TIMEOUT=30 # 优雅退出等待时间（秒）
REDIS_STREAM_MAX_LEN=10000         # Redis Stream 最大消息数（自动裁剪）
REDIS_CONSUMER_GROUP=workers       # Redis Stream 消费者组名

# ─────────────────────────────────────────
# HITL 配置
# ─────────────────────────────────────────
HITL_DEFAULT_TIMEOUT_HOURS=24      # HITL 默认超时时间
HITL_DEFAULT_ACTION=cancel         # 超时后默认动作：cancel | proceed

# ─────────────────────────────────────────
# 限流配置
# ─────────────────────────────────────────
RATE_LIMIT_REQUESTS_PER_MINUTE=60  # 每用户每分钟最大请求数
MAX_CONCURRENT_TASKS_FREE=3        # free 用户最大并发任务数
MAX_CONCURRENT_TASKS_PRO=10        # pro 用户最大并发任务数

# ─────────────────────────────────────────
# 应用配置
# ─────────────────────────────────────────
APP_ENV=development                # development | production
APP_HOST=0.0.0.0
APP_PORT=8000
LOG_LEVEL=INFO                     # DEBUG | INFO | WARNING | ERROR
CORS_ORIGINS=http://localhost:3000 # 允许跨域的前端地址，多个用逗号分隔
```

### 本地开发 `docker-compose.yml`（基础设施快速启动）

```yaml
services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: agent_user
      POSTGRES_PASSWORD: your_pg_password
      POSTGRES_DB: agent_db
    ports:
      - "5432:5432"
    volumes:
      - pg_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    command: redis-server --maxmemory 256mb --maxmemory-policy allkeys-lru
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

volumes:
  pg_data:
  redis_data:
```

启动命令：`docker compose up -d`
