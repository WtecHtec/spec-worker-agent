# Agent Runtime 鉴权机制与多租户隔离设计规范

## 1. 鉴权架构概述

Agent Runtime 部署于内部私有网络（监听 8123 端口），采用 **“网络层内外隔离 + 内部 JWT 零信任通信 + 行级数据资源隔离（Row-Level Security）”** 的多层纵深防御体系。

```
[外部用户] ──(持有 User Access Token)──> [FastAPI 后端网关]
                                                 │
                                签发内部短效凭证 (TTL 60s)
                                mint_internal_jwt(user_id)
                                                 │
                                                 ▼
                                        [Agent Runtime (8123)]
                                          └── langgraph.json
                                                └── auth.py:my_auth
```

---

## 2. 核心鉴权组件（[auth.py]( /agent-runtime/auth.py)）

### 2.1 挂载与加载机制
在 [langgraph.json]( /agent-runtime/langgraph.json) 中配置：
```json
{
  "auth": {
    "path": "./auth.py:my_auth"
  }
}
```
服务启动时，LangGraph API 引擎将 `my_auth` 自动注册到底层 Starlette 中间件栈，保护所有端点（`/threads`, `/runs/stream`, `/history`, `/state` 等）。

---

### 2.2 身份验签钩子：`@my_auth.authenticate`
```python
@my_auth.authenticate
async def authenticate(authorization: str) -> Auth.types.MinimalUserDict:
    if not authorization:
        raise ValueError("Missing authorization header")
    token = authorization.removeprefix("Bearer ").strip()
    try:
        payload = verify_internal_jwt(token)
        user_id = payload.get("user_id")
        if not user_id:
            raise ValueError("user_id not in token payload")
        return {"identity": user_id}
    except JWTError as e:
        raise ValueError(f"Invalid internal token: {e}")
```
- **核心逻辑**：
  1. 从请求头提取 `Bearer <internal_token>`；
  2. 使用共享私钥 `INTERNAL_JWT_SECRET`（HS256）验证签名并检查过期时间；
  3. 解密出真实 `user_id`，若非法直接中断请求并响应 401/400；
  4. 验证通过后注入到 LangGraph 请求上下文：`ctx.user.identity = user_id`。

---

### 2.3 多租户线程行级隔离钩子：`@my_auth.on.threads`
```python
@my_auth.on.threads
async def authorize_threads(ctx: Auth.types.AuthContext, value: dict):
    """Thread 资源自动按用户身份隔离"""
    return {"owner": ctx.user.identity}
```
- **工作机制**：
  - **Thread 创建时**：LangGraph Checkpointer 底层自动将该记录打上 `owner = user_id`；
  - **Thread 查询/修改/执行时**：LangGraph 引擎自动在数据库查询条件中增加 `WHERE owner = ctx.user.identity`；
  - **防护效果**：任何非该 Thread 创建者的请求，即使猜中 `thread_id`，也会被直接拒绝或视为不存在，物理级隔绝跨租户越权。

## 3. 内部短效 JWT 规范
- **算法**：HS256
- **有效期**：60 秒（短效防重放）
- **Payload 字段**：
  ```json
  {
    "user_id": "e5a3b6a1-e5b5-4d59-a5e4-1f3daf4a5f33",
    "iat": 1725376800,
    "exp": 1725376860,
    "scope": "internal_agent_runtime"
  }
  ```
- **签发方**：后端网关（`src.application.auth.internal_jwt.mint_internal_jwt`）；
- **验签方**：Agent Runtime（`auth.verify_internal_jwt`）。
