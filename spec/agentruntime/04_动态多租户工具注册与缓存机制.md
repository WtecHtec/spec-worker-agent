# Agent Runtime 动态多租户工具注册与缓存机制设计规范

## 1. 架构目标与多租户挑战

不同用户（Tenant）拥有不同的权限、绑定的私有 MCP 服务（如本地 GitHub、企业内部知识库、私有 Docker 沙箱）及协同的 A2A 外部专家智能体。
智能体不能使用全局写死的单一工具池，必须具备：
1. **多租户隔离**：工具仅对所属用户可见与执行；
2. **纯内存秒级命中**：避免每次 LLM 推理均查询数据库，吞吐量提升 100 倍；
3. **动态热刷新（Cache Invalidation）**：当用户在设置面板新增/修改/禁用 MCP 或 A2A 工具时，实时感知并精准失效该用户的内存缓存。

## 2. 核心架构设计（[manager.py]( /agent-runtime/src/tools/manager.py)）

```
                     [PostgreSQL (mcp_servers, a2a_agents)]
                                        │ (用户修改配置)
                                        ▼
                     [Redis PubSub Channel: agent_tools_invalidation]
                                        │
                         广播消息: {"user_id": "xxx"}
                                        │
                                        ▼
                     ┌──────────────────────────────────────┐
                     │ MultiTenantToolManager               │
                     │  ├── _user_registries: dict[uid, ...]│
                     │  └── invalidate_user(user_id)        │
                     └──────────────────────────────────────┘
                                        │
                     ┌──────────────────┴───────────────────┐
                     ▼                                     ▼
           命中缓存 (99.9% 请求)                 首次加载 / 缓存失效
           直接返回 ToolRegistry                 从数据库组装最新 ToolRegistry:
                                                  ├── Builtin (计算器等)
                                                  ├── Sandbox (沙箱读写/执行)
                                                  ├── MCP (协议适配器工具)
                                                  └── A2A (专家协同工具)
```

## 3. 四层工具统一契约（BaseTool）

所有工具继承自统一的基类 [src/tools/base.py]( /agent-runtime/src/tools/base.py)：
```python
class BaseTool(ABC):
    @property
    @abstractmethod
    def name(self) -> str: ...

    @property
    @abstractmethod
    def description(self) -> str: ...

    @property
    @abstractmethod
    def parameters(self) -> dict[str, Any]: ...

    @abstractmethod
    async def execute(self, ctx: dict[str, Any], **kwargs: Any) -> ToolResult: ...
```

### 工具生态分类：
1. **内置工具（Builtin）**：
   - `calculator`：高精数学与代数计算；
   - `hitl_request_input`：主动人机表单收集。
2. **沙箱工具（Sandbox）**：
   - `sandbox_bash`：隔离容器命令执行；
   - `sandbox_write_file`：文件写盘并自动直连 PostgreSQL 同步持久化；
   - `sandbox_read_file`：工作区文件读取。
3. **MCP 适配器（MCPAdapterTool）**：
   - 动态将第三方 MCP Server 的 Tools 规范映射为标准 `BaseTool`，具备超时熔断。
4. **A2A 专家协同工具（A2AExpertTool）**：
   - 将外部注册的专业智能体包装为工具，主智能体可通过函数调用跨网络直接派发子任务。

## 4. 广播驱动的精准缓存失效（Event-Driven Invalidation）

1. **发布端（Backend 网关）**：
   当用户在设置中增删改 MCP 或 A2A 记录时，向 Redis 频道 `agent_tools_invalidation` 投递：
   `PUBLISH agent_tools_invalidation {"user_id": "xxx"}`；
2. **消费端（Agent Runtime）**：
   后台守护任务 `_listen_invalidation_events` 实时消费事件，仅剔除目标用户的 `_user_registries[user_id]`，其他在线用户缓存完全不受干扰；
3. **按需重载**：
   该用户下一次发起对话时，自动以最新的数据库配置重构 `ToolRegistry` 并重新缓存。
